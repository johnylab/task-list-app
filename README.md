# Task List App

Exercício: o mesmo aplicativo de lista de tarefas feito de formas diferentes, **uma branch por técnica**.

| Branch | Abordagem |
|---|---|
| `master` | TypeScript (`js/*.ts`) com publicação automática no GitHub Pages (GitHub Actions) |
| `typescript` | TypeScript, igual à `master` sem o workflow de publicação |
| `vanilla` | JavaScript puro (`js/index.js`) |

## Rodando
```
git checkout <branch>
npm install
npm run dev
```
